Move internal communication to UNIX socket. The `INTERNAL_TOKEN` can now be dropped from the configuration, and the UNIX socket path can be configured using the `INTERNAL_LISTENER_PATH` options. This change removes the `./forgejo generate secret INTERNAL_TOKEN` command and updates the contrib Forgejo systemd unit file. The `forgejo.service` example systemd file has been updated to set `RuntimeDirectory=forgejo`, which is a recommended setting for all systemd users.<br>See the [documentation](https://forgejo.org/docs/latest/admin/config-cheat-sheet/#server-server) for more information.
